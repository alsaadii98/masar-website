# Masar Maps

A responsive, animated coming-soon page for Masar Maps, in English and Arabic.

Target domain: **masarmaps.com**.

## Website

The complete page is `site/index.html`. The Masar SVG logo, favicon, fonts, styling, and animations are embedded. No build, JavaScript framework, or external assets are required.

Open `site/index.html` directly in a browser for a local preview. The page respects reduced-motion preferences. Font licenses are retained in an inert template inside the HTML.

## Publishing

`.github/workflows/pages.yml` publishes only the `site` directory to GitHub Pages on each push to `main`. It can also be run manually from the Actions tab. It uses GitHub's built-in deployment token; no Hostinger secret is needed.

Before the first deployment, set the repository's **Settings → Pages → Build and deployment → Source** to **GitHub Actions**.

Set **Settings → Pages → Custom domain** to `masarmaps.com` before pointing DNS to GitHub. Enable **Enforce HTTPS** when the certificate is ready.

The `site/CNAME` file records the target domain for compatibility. With a custom Actions workflow, GitHub uses the domain in Pages settings; the CNAME file does not configure it.

Read `DNS_SETUP.md` for the website DNS targets and email-preservation procedure. DNS is configured once at the DNS provider. Subsequent pushes deploy the website without modifying the email configuration.

## Updating the page

Edit `site/index.html`, commit, and push to `main`. Check the `Publish Masar Maps` workflow for the deployment result.

## Store pages

The App Store and Google Play pages are generated by `tools/build_pages.py` (content for Arabic, English and Kurdish Sorani lives in that file). Edit the content there, then run:

```bash
python3 tools/build_pages.py
```

| Page | Arabic (default) | English | Kurdish |
|---|---|---|---|
| Privacy Policy | `/privacy` | `/en/privacy` | `/ckb/privacy` |
| Terms of Use | `/terms` | `/en/terms` | `/ckb/terms` |
| Delete account | `/delete-account` | `/en/delete-account` | `/ckb/delete-account` |
| Support | `/support` | `/en/support` | `/ckb/support` |

Shared assets are in `site/assets`: stylesheet, logo, mascot and avatars, Vazirmatn (OFL, WOFF2 with its licence; the other font files stay for the OG image tool and /legal), Material Symbols Rounded icons (Apache 2.0, `assets/icons/material`). The look is direction B «Friendly mascot» on the app's v5 style (IraqWaze `docs/design/v5/STYLE.md`): cyan bands with the mascot and avatars, readable content cards, cyan footer. No app screenshots on the site for now. The home page stays a coming-soon page; it only links to these pages in its footer.

## SEO

- `/waze-alternative` (ar), `/en/waze-alternative`, `/ckb/waze-alternative`: landing page for searches about the Waze ban in Iraq (بديل ويز في العراق، حظر تطبيق ويز، مصطفى سند تطبيق ويز). Ban facts are attributed to press reports; update `landing()` in `tools/build_pages.py` if the date changes.
- Every page has a canonical URL, hreflang alternates, Open Graph / Twitter tags (`site/assets/og-image.png`, source `tools/og/og.html`) and JSON-LD (Organization, WebPage; MobileApplication and FAQPage on the landing page).
- `robots.txt` and `sitemap.xml` are generated by the build script.

## App links (.well-known)

`site/.well-known/assetlinks.json` and `site/.well-known/apple-app-site-association` are generated by the build script. Set `APPLE_TEAM_ID` and `ANDROID_SHA256` in `tools/build_pages.py` once the store accounts exist, and rebuild. The workflow packages the site itself because `actions/upload-pages-artifact` drops dot-directories.

## Shared places (/p)

The apps open `https://masarmaps.com/p?ll=<lat>,<lon>&n=<name>` as app links (paths in `APP_LINK_PATHS`). Without the app, `/p` (and `/en/p`, `/ckb/p`) shows the place name and coordinates, "Open in Masar" (an Android `intent:` link with a Play fallback; the same URL elsewhere), "Get the app" and "Open in a map" (`geo:` on Android, OpenStreetMap elsewhere). The page is `noindex`. Set `APP_STORE_URL` in `tools/build_pages.py` when the iOS app is live.
